# Buffaverse scope registry

| Identifier | Status | Depends on | Notes |
|---|---|---|---|
| phase-0 | foundation | — | architecture and product foundation |
| phase-1 | approved baseline | phase-0 | event-engine foundation |
| phase-2 | reconciliation | phase-1 | Legendary Restaurants |
| phase-3 | gated | phase-2 | Restaurant Boss Battles |
| phase-4 | `data_deferred` | phase-3 evidence only | Wing Master; not an active prerequisite |
| phase-5 | existing approved scope | phase-3 | identifier preserved; does not require phase-4 while deferred |
| phase-6 | existing approved scope | existing approved prerequisites excluding phase-4 | identifier preserved |

The registry is intentionally noncontiguous. Consumers must use identifiers,
not array position or `phase + 1` arithmetic.
