# Local Android setup

Use the existing Windows Android Studio installation and connected `emulator-5554` (`Medium_Phone_API_36.1`). Java 21 is required; use `C:\Program Files\Android\Android Studio\jbr`. Java 25 is not required. Verify `adb`, `maestro`, the Android package `com.buffago.app`, and Metro availability with `scripts/cayenne/check-prerequisites.ps1`.
