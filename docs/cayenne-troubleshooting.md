# Troubleshooting

For Java, point `JAVA_HOME` to `C:\Program Files\Android\Android Studio\jbr`; do not install Java 25 for Cayenne. Check `adb devices`, boot completion, package installation, and Metro before blaming a selector. Maestro permission prompts vary by emulator state, so reset only the app when appropriate. Runtime logs are filtered/redacted artifacts, not a place to add secrets. iOS validation is blocked on this Windows Android-only setup; OAuth and remote push delivery require external provider setup.
