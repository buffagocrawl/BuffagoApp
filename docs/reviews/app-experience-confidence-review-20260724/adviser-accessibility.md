Strengths: safe-area tabs, labels, keyboard avoidance, reduced-motion utilities, component library. Risks: targets, dynamic type, contrast, focus order, modal traps, icon-only controls, announcement timing, motion, map accessibility, error persistence. Simplify: dense cards, decorative motion, multi-action sheets. Clarify: labels, status changes, error recovery. Hide: inaccessible advanced surfaces until audited. Emphasize: readable rating and obvious actions. First screen/journey: Home / auth-rating. Confusing: icon-only Journey / Buffaverse. Strongest/weakest: auth keyboard handling / untested custom surfaces. Abandon/uninstall: cannot read/operate / inaccessible motion or focus. Recommend/reopen: accessible useful finder / reliably operable tasks. Pre-beta: TalkBack + largest text test. Post-beta: assisted usability audit.

More game less Yelp: game presentation must not obscure controls. Coherent: only if semantics are plain. Early concepts: harmful at large text. Buffaverse: hide until labelled.
