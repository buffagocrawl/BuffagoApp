# Recovery journey

OAuth cancellation has explicit cancellation messaging in source; keyboard avoidance and cancellation exist on sign-in. Notification deep-link, privacy, migration and referral contracts exist. Network failure, permission denial, empty search, interrupted crawl/backgrounding, stale notification, unsaved profile, and accidental back are primarily CI/CV—not live validated.

Release implication: retain the existing hard gate for live auth/notification/Supabase/RLS/deletion evidence. Experience implication: add no speculative error UI; test existing recovery states in a configured QA adapter before public beta.
