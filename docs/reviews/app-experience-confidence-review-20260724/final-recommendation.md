# Final recommendation

Internal beta: **conditional / do not release until existing release gates are closed.** Once a safe QA environment supplies live evidence, make only the five ranked focus/accessibility changes and validate their flows. Public beta: **not recommended** until release blockers, security containment evidence, and initial usability evidence are closed.

Before beta: lead with rate/find wings; reduce early concepts; contextualize or unlock Buffaverse later; clarify branded terms; verify accessibility. Learn during beta: task comprehension, onboarding drop-off, CTA choice, D1/D7, social density, referral timing, notification usefulness and Buffaverse demand. Do not change: the core rating reward loop, useful mascot moments, or navigation wholesale; do not build speculative social/currency/Buffaverse systems.
