# Copy advice

Keep distinctive brand terms when paired with a plain-language cue: **Wingdex** → “Wingdex — find and rate wings”; **Crawl** → “Wing Crawl — a multi-stop wing run”; **Mission** → “Today’s goal”; **Streak** → “Days you’ve rated”; **XP** → “Progress points”; **Passport** → “States you’ve explored”; **Badge/Title** → “Achievement/Your title”; **Buffaverse** → “Legendary wing challenges”; referral qualification → “Invite friends after you’ve completed [rule].”

Reward: “Rating saved — +X XP.” Locked: “Rate X more places to unlock this.” Error: name the action, preserve input, give retry. Avoid unexplained “qualification,” “legendary,” and multiple reward nouns on one screen. These are alternatives for testing, not mandated rebrands.
