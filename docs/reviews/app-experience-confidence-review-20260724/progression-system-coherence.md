# Progression-system coherence

| System | Purpose/action/reward | Introduction / relationship / burden | Recommendation |
|---|---|---|---|
| XP | Recognize ratings/activity; XP | After first rating; primary | Keep primary |
| Streaks, missions | Return prompts; XP | After rating; support XP | Reveal progressively |
| Passport, badges, titles | Collection/status | After activity; presentation of progress | Combine in Journey |
| Crawls, Wing Battle | Multi-stop activity; coins/completion | When planning a night out | Optional activity, not core progression |
| Referrals, social | Invite/community | Only after value and density | Hide until qualifying context |
| Buffaverse | Advanced legendary layer | feature-flagged off | Later opt-in / do not make another primary system |

Decision: primary progression is **ratings → XP → visible personal progress**. Supporting systems are streak/missions and Passport/status. Explain collection only after activity; hide social/referral and Buffaverse until meaningful activity. Buffaverse is currently another feature, not a credible umbrella without consolidation work.
