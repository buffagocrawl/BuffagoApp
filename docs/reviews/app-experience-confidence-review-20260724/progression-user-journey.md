# Progression-user journey

XP, streaks, missions, Passport, badges, titles, Crawls, Wing Battle, referrals and Buffaverse are individually understandable only with explanation; together they currently risk reading as several reward systems. CI confirms their existence, no participant comprehension evidence exists.

Recommendation: declare XP for ratings as primary; use missions/streak as return prompts; Passport/badges/titles as collection/status; Crawls as an activity; referrals/social only after value; Buffaverse as later/opt-in. Do not score depth or motivation above CI confidence.
