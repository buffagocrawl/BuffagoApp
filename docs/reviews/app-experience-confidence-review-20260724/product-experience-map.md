# Product-experience map

| Feature / entry | User belief and expected action | Value/progress/exit | Timing, core-loop fit, burden, evidence |
|---|---|---|---|
| Launch / signed out | “This finds and rates wings”; sign in or browse | Gateway; exit Home/Wingdex | Required auth for contribution; wording must earn it. EV/CI |
| Google / Facebook auth | Continue with an identity provider | Account and return to Home | Optional provider; Facebook only when configured. CV/CI; provider live evidence absent |
| Onboarding / state / preferences | Set where and what to explore | Personalized restaurant set; exit discovery | Required sequence; can be too much before value. EV/CI |
| Restaurant discovery / Wingdex / map | Find a wing spot; choose list/map and restaurant | Restaurant detail, proximity context | Core loop, prominent. CI/partial EV |
| Restaurant detail / rating | Judge wings with scores/tags and submit | Rating, XP/reward, next action | Core loop; reward is direct. CV/CI |
| First reward / Home | “I made progress; what now?” | XP, daily action, next spot | Core loop reinforcement but Home aggregates many concepts. CI |
| Crawls / Wing Battle | Follow a multi-stop social challenge | Stops, coins/reward, completion | Optional supporting loop; introduce after a rating. CI |
| Missions / streak | Return and complete a daily goal | XP/status | Optional retention prompts; can compete with rating. CV/CI |
| Notifications | Open a relevant action | Deep-link target / recovery | Optional; CV, no PD/PO delivery evidence |
| Passport / badges / titles | Collect state and status progress | Visible collection/status | Optional support systems; progressive reveal. CI |
| Buffaverse | Advanced legendary/progression space | Event/progression reward | Default disabled; ambiguous as a primary concept. CI |
| Referrals / social / leaderboards / friends | Invite, compare, and connect | Community and status | Optional; referrals safety-gated, social needs density. CV/CI |
| Profile / settings / deletion | Control identity, preferences, account | Saved setting or deletion confirmation | Required trust controls; deletion CV, live proof absent |

All progress systems are optional except setup/auth needed for contribution. Existing source exposes five tabs (Home, Crawls, Wingdex, Social, Journey); that is coherent navigation mechanically but concept-heavy before the first rating.
