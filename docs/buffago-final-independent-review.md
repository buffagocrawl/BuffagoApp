## Engineering conclusions

The adapter has one bounded production entrypoint and no import-time connection. It binds signed Ed25519 decisions to target, action, actor, artifact hashes and time window; enforces direct host/5432/postgres, verified TLS/SCRAM, pinned psql17.6 and nonsuper BYPASSRLS session identity; refuses ambient PG overrides; and uses durable external evidence before sending migration SQL. Trust roots, protected credentials/ACLs, dependent DLLs and control-plane mapping remain independent provisioning responsibilities.

The shared attempt state machine preserves primary SQLSTATE and write/COMMIT status if failure evidence also fails, closes transport before evidence cleanup, and never automatically replays a write. COMMIT acknowledgment is followed by an independent read-only connection. Recovery compares ledger and full catalog in one common MVCC statement; only approved exact pre/post states classify rollback/commit. A missing, drifted or inconsistent state remains unknown/mixed. No production pre/post digest has been adopted.
