## Cross-panel product work ledger

1. Implement and render the Legendary proposition, not only the schema.
2. Build a deterministic showcase fixture system covering every requested lifecycle, density, accessibility, and failure state.
3. Add one dominant hero CTA and one compact mission sentence across home, map callout, restaurant detail, and full detail.
4. Make the map marker distinctive by shape, icon, label, selected treatment, and cluster behavior—not color alone.
5. Make completion a real state transition with mascot, reduced-motion fallback, honest pending recognition, next action, and share.
6. Make pre/post completion sharing understandable to a non-Buffago recipient.
7. Add useful, honest low-density and permission-denied states.
8. Produce executable rendered, accessibility, performance, notification, and runtime evidence.

Repository migration integrity is not an open gate in this mapping. It remains a passing prerequisite unless new drift is discovered.
