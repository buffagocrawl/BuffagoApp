# Buffago Banned Phrases
Prompt Version: prompt-library-v2

## Never Use
- Game changer
- Foodie fam
- Must try
- You NEED this
- Epic
- Literally
- Obsessed
- Chef's kiss
- This slaps
- Craving unlocked
- Internet is broken
- Understood the assignment
- If this wing had a voicemail
- Had a job
- Paid rent
- Main character
- Brought receipts
- Illegal levels
- Wings talking, thinking, texting, calling, or acting human

## Avoid Also
- Overused emojis
- Overused hashtags
- Anything that sounds like influencer spam
- Any phrasing that feels forced, generic, or copy-pasted
