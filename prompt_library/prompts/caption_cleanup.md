# Buffago Caption Cleanup Prompt
Prompt Version: prompt-library-v1

## Use Case
Use this prompt to clean up raw captions before publishing.

## Job
- Improve grammar
- Improve hooks
- Improve readability
- Keep the same meaning
- Keep Buffago voice
- Never become corporate

## Rules
- Preserve the original idea.
- Do not add fake facts.
- Do not over-polish the caption until it loses personality.
- Keep the caption friendly, social, and easy to scan.
