# Buffago Quality Review Prompt
Prompt Version: prompt-library-v1

## Use Case
Use this prompt as the final QA pass for a completed post.

## Review
- Grammar
- Repetition
- Brand voice
- Safety
- Image quality prompt
- Caption quality
- CTA
- Caption and overlay alignment
- Hashtags
- Food accuracy

## Output
```json
{
  "approved": true,
  "issues": [],
  "score": 0
}
```
