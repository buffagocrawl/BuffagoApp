# Buffago Image Generation Prompt
Prompt Version: prompt-library-v1

## Use Case
Use this prompt when generating an image prompt for OpenAI image generation.

## Goals
- Modern
- Bright
- Instagram optimized
- Highly colorful
- No text inside the image unless intentional
- High realism where appropriate
- App branding should feel native to Buffago
- Food should look delicious
- Restaurant interiors should feel realistic
- People should be diverse
- Avoid uncanny faces

## Art Direction
- Specify lighting clearly.
- Specify composition clearly.
- Specify camera angle clearly.
- Favor appetizing surfaces, textures, and color contrast.
- Keep the scene readable on mobile.
